# Plan de implementación

Solo M0 autorizado. Estados y evidencia: matriz-de-funciones.md y validacion-m0.md.

| Hito | Alcance                                                               | Criterios de aceptación verificables                                                                                                                                                                                                                                                               |
| ---- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| M0   | Scaffold, MV3, popup honesto, opciones, ES/EN, tema, familia DotPilot | build/lint/typecheck/test correctos; manifest de producción con activeTab/scripting/storage autorizado, sin hosts ni content_scripts; carga descomprimida sin errores; 8 vistas (2 superficies × 2 idiomas × 2 temas), persistencia y teclado; iconos 16/32/48/128; fuentes de tokens documentadas |
| M1   | Visible → editor básico → PNG                                         | Gesto explícito; error útil en página restringida; flecha/rectángulo/texto editables; censura opaca elimina píxeles recuperables; PNG decodificable con dimensiones correctas y alfa; cancelar sin residuo; DPR 1/1.25/2; estado sobrevive suspensión o falla limpiamente                          |
| M2   | Región + elemento inteligente                                         | Recorte coincide con selección y zoom/DPR; hover no altera layout; Escape limpia overlay; scroll y navegación cancelan/revalidan; iframes sin acceso muestran límite; sin nueva inyección permanente                                                                                               |
| M3   | Página completa                                                       | Cola ≥600ms entre llamadas, reintentos acotados; fixed/sticky y lazy load probados; restaura scroll/estilos al cancelar/error; prueba páginas largas y áreas superiores al presupuesto; salida segmentada documentada, sin canvas gigante ni unión silenciosa                                      |
| M4   | JPEG/WebP/PDF + peso                                                  | Firmas/MIME reales; transparencia JPEG aplanada con color elegido; PDF multipágina con dimensiones coherentes; optimización PNG real con evaluación decodificada; objetivo de peso solo cuando se logra, muestra resultado real; paquetes offline y licencias auditados                            |
| M5   | Historial, ajustes completos, atajos                                  | Cuotas y borrado local probados; sin historial incógnito; preferencias migradas; ≤4 suggested_key, conflictos visibles; sin downloads salvo justificación aprobada                                                                                                                                 |
| M6   | Tienda, documentación y pruebas                                       | Nombre y marca revisados; icono definitivo; privacidad coherente con tráfico cero; ZIP instalable, pruebas Chrome por versión/OS; Edge documentado solo si probado; accesibilidad/seguridad y recuperación sin errores; ninguna función futura anunciada como disponible                           |

Pruebas de M1–M6 aún pendientes. Cada hito exige evidencia (comando/versión/resultado o captura), revisión de permisos y actualización de documentos antes de declararlo probado. No se ha hecho ningún benchmark de captura, canvas o memoria en M0.
