# Supuestos y decisiones

Fecha: 21 de octubre de 2026. Solo Fase 0 + M0. Ningún compromiso comercial ni integración externa.

| Decisión                                                              | Justificación y alcance                                                                                                                                                                                                        | Estado                                                                        |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| WXT + TypeScript estricto + React                                     | Entrypoints MV3, empaquetado e integración React; no se encontró razón para cambiar a CRXJS.                                                                                                                                   | Adoptada; reversible                                                          |
| Nombre único en src/shared/config/product.ts                          | Nombre visible en React y productName de ambos catálogos de Chrome generado al compilar; no editar copias del nombre. El identificador npm/ruta no es marca visible.                                                           | Adoptada; reversible                                                          |
| activeTab y scripting                                                 | Acceso temporal tras gesto e inyección futura bajo demanda; sin permisos de hosts, debugger ni downloads. Aún sin uso de captura.                                                                                              | Adoptada; reversible                                                          |
| Añadir storage                                                        | chrome.storage exige storage. Usuario lo autorizó expresamente en este chat el 21/10/2026. Sustituye el criterio original de exactamente dos permisos por activeTab, scripting y storage. Solo preferencias locales, sin sync. | Autorizada e implementada; reversible                                         |
| Sin editor/PDF/optimizadores instalados                               | Comparativa es propuesta para hitos posteriores.                                                                                                                                                                               | Adoptada; reversible                                                          |
| Preferencias Sistema por defecto                                      | es-* → ES, resto → EN; apariencia del SO con prefers-color-scheme. Cambios compartidos entre popup y opciones por storage.onChanged.                                                                                           | Implementada; reversible                                                      |
| Manifest default_locale es                                            | Manifest/Chrome siguen idioma del navegador; selector interno modifica React, no la localización del manifest. Misma fuente y claves, sin traducciones duplicadas.                                                             | Adoptada; reversible                                                          |
| incognito split                                                       | Contextos de incógnito separados; chrome.storage.local sigue compartido para preferencias. No guardar imágenes ni URLs en M0. Requiere activación manual por usuario.                                                          | Adoptada; reversible                                                          |
| Ajustes/Historial deshabilitados + enlace explícito a preferencias M0 | Cumple el rotulado Próximamente sin bloquear los dos selectores ya disponibles.                                                                                                                                                | Implementada; reversible                                                      |
| Chrome mínimo 120                                                     | Base MV3 moderna conservadora, no equivale a haber probado versiones antiguas.                                                                                                                                                 | Supuesto; reversible                                                          |
| Paleta clara adaptada y bordes accesibles                             | DotPilot depende de VS Code; distinguir tokens encontrados de supuestos.                                                                                                                                                       | Adoptada; reversible                                                          |
| Sin licencia de distribución declarada aún                            | No asignar derechos de autor ni licencia del producto sin decisión del titular; dependencias conservan sus licencias. Repositorio privado por defecto.                                                                         | Pendiente antes de publicar                                                   |
| DotSnap e icono provisionales                                         | Disponibilidad comercial/marcas pendiente; no se ha hecho búsqueda jurídica ni afirmación de disponibilidad. «Snap» requiere revisión antes del lanzamiento.                                                                   | Pendiente; cambiar nombre es reversible; publicación comercial exige revisión |

El lockfile fija las versiones resueltas. Instalación de herramientas npm requiere red de desarrollo; el artefacto final no carga CDN, fuentes, scripts ni analítica. No eval ni permisos WASM en M0. Los permisos de futuros hitos se justificarán aquí antes de añadirlos.

No hay costes, servicios ni decisiones de privacidad pendientes que impidan M0. M1 requiere aprobación explícita del usuario.

Los logs de evidencia se conservan tal como salieron, incluido el espaciado de consola.
